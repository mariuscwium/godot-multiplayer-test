# Pixel-art Terrain Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Draw brick, steel, water, ice, bush and ground from pixel-art tiles instead of code-drawn rectangles, with no behaviour change.

**Architecture:** A one-row tile strip `assets/terrain.png` (cut from the author's licensed atlas by a small tool) plus a pure lookup class `TerrainTiles` that maps (terrain, cell, time) to a source rect. `Render` draws each 8 px cell from the matching quarter of its 16x16 tile with nearest-neighbour filtering.

**Tech Stack:** Godot 4.7.2 / GDScript, existing headless test runner (`tools/test.sh`).

**Spec:** `docs/superpowers/specs/2026-11-16-pixel-terrain-design.md`

## Global Constraints
- Source atlas: `/mnt/c/Users/wium/Downloads/Textures-16.png` ("Textures" by piiixl, https://piiixl.itch.io/textures: free for games, no redistribution as-is); copy only the used tiles into the repo, never the whole atlas.
- Tile picks, (column, row) in the 16 px source grid: ground (0,10), brick (3,3), steel (8,4), water (6,8) (7,8) (8,8), ice (3,11), bush (2,16).
- Cells stay 8 px (`Cfg.CELL`); tiles are 16x16, so a cell draws the quarter at (`posmod(cx,2)`, `posmod(cy,2)`).
- No gameplay, network or simulation change; tanks, bullets, power-ups and HUD stay as drawn today.
- Bush must still hide other tanks and bullets (draw order unchanged); your own tank stays on top.
- Work on branch `battle-city`; commit only the files named in each task.

## Review Focus
1. Odd and negative cell coordinates must sample the right quarter (`posmod`, not `%`): the visible-cell loop can include cells just outside the map (Task 1 test).
2. `assets/terrain.png` missing or unimported: the game must fail loudly in dev, never silently draw nothing (Task 2 step).
3. The web export must include the texture and show it (Task 2 verification in headless Chromium).
4. Pixels must stay crisp at the ~3x camera zoom, with no blur or seams between neighbouring tiles (Task 2 screenshot check at the tile joins).
5. Bush must still hide other tanks (Task 2 screenshot check with a bot in a bush).

## File Structure
- Create `scripts/terrain_tiles.gd` (`TerrainTiles`): pure tile-index and source-rect lookup.
- Create `assets/terrain.png` (128x16, 8 tiles in one row): generated by `tools/pack_terrain.gd`.
- Create `tools/pack_terrain.gd`: cuts the picked tiles from the source atlas into the strip.
- Modify `scripts/render.gd`: draw terrain through `TerrainTiles`; remove the code-drawn tile functions and colour constants.
- Modify `README.md`: credit line. Tests in `tests/test_terrain_tiles.gd`.
